# Nour-AI — وكيل الذكاء الاصطناعي التجاري

**Nour-AI** ذكاء اصطناعي تجاري من **FoxSD**: تكلّمه بالعربية فيفهم طلبك، ويجيبك، **ويبنيه فعليًا** —
مواقع، تطبيقات، برامج، سكربتات، وأنظمة تشغيل. يكتب الملفات، يشغّلها، ويختبرها بنفسه.

- **الشركة:** FoxSD
- **الاسم المختصر:** Fox
- **التواصل:** foxsd520@gmail.com

## المكوّنات

| الملف | الوظيفة |
|---|---|
| `nour_server.py` | خادم الويب (واجهة API + بث حي) |
| `nour_web.html` | واجهة المحادثة العربية |
| `nour_core.py` | النواة: الهوية، المحرّك، الذاكرة، البناء |
| `nour_ai.py` | الوكيل الطرفي (CLI) |

## التشغيل

```bash
pip install -r requirements.txt
python -m uvicorn nour_server:app --host 0.0.0.0 --port 8000
```

ثم افتح: <http://localhost:8000>

### أو من الطرفية

```bash
python nour_ai.py "ابنِ لي موقعًا تعريفيًا لشركة FoxSD"
python nour_ai.py            # وضع تفاعلي
```

## المزايا

- **محادثة حقيقية** بالبث الحي (SSE) — الرد يظهر كلمة بكلمة.
- **بناء فعلي**: يستدعي أداة `build_project` فيكتب ملفات المشروع ويشغّلها ويختبرها.
- **ذاكرة دائمة**: كل جلسة تُحفظ في `data/sessions/` وتُستعاد عند العودة.
- **تقدّم مباشر**: ترى كل خطوة (إنشاء ملف، تشغيل اختبار) لحظة حدوثها.
- **استعراض الملفات**: اضغط أي ملف في الواجهة لعرض محتواه.

## واجهة الـ API

| المسار | الوصف |
|---|---|
| `GET /api/health` | حالة الخدمة والمحرّك |
| `GET /api/history?session_id=` | سجل المحادثة |
| `POST /api/chat` | محادثة (بث SSE) — تبني تلقائيًا عند طلب البناء |
| `POST /api/build` | بناء مباشر |
| `GET /api/projects/{p}/files` | ملفات مشروع |
| `GET /api/projects/{p}/file?path=` | محتوى ملف |
