# Nour-AI — وكيل الذكاء الاصطناعي التجاري

**Nour-AI** ذكاء اصطناعي تجاري من **FoxSD**: تكلّمه بالعربية فيفهم طلبك، ويجيبك،
**ويبنيه فعليًا** — برامج، مواقع، أنظمة، سكربتات — ثم **يختبر الناتج بنفسه** حتى ينجح.

## الهوية

- **المنتج:** Nour-AI
- **الشركة:** FoxSD
- **الاسم المختصر:** Fox
- **التواصل:** foxsd520@gmail.com

قاعدة ذهبية: كل مخرَج يحمل اسم **FoxSD** وبيانات التواصل فقط، ولا يذكر أي جهة أخرى.

## المكوّنات

| الملف | الوظيفة |
|---|---|
| `foxsd_engine.py` | محرّك FoxSD الداخلي: عميل المحادثة، الأدوات، وحلقة الوكيل |
| `nour_core.py` | النواة: الهوية، صلاحية المحرّك، الذاكرة، البناء الحقيقي |
| `nour_server.py` | خادم الويب (واجهة API + بث حي) |
| `nour_web.html` | واجهة المحادثة العربية |
| `nour_ai.py` | الوكيل الطرفي (CLI) |
| `site/index.html` | صفحة FoxSD |

## التشغيل

```bash
pip install -r requirements.txt

# خادم الويب
python -m uvicorn nour_server:app --host 0.0.0.0 --port 8000

# الوكيل الطرفي
python nour_ai.py "ابنِ لي آلة حاسبة"
```

ثم افتح: `http://localhost:8000`

## المميزات

- بث حي للردود عبر SSE
- بناء مشاريع حقيقية: كتابة ملفات، تشغيل أوامر، اختبارات فعلية
- ذاكرة دائمة تحفظ ما بنيته عن المستخدم
- جلسات محادثة محفوظة مع عارض ملفات
- هوية FoxSD مقفلة في كل مخرَج
- محرّك داخلي بلا أي اعتماد على مزوّد خارجي
