# Nour-AI — وكيل البناء الذكي

**Nour-AI** وكيل ذكاء اصطناعي تجاري من **FoxSD**. يسمع طلبك بالعربية ثم يبنيه فعليًا:
برامج، مواقع، تطبيقات، سكربتات، وأنظمة تشغيل — يكتب الملفات ويشغّلها ويختبرها بنفسه.

## القاعدة الذهبية

كل مخرَج يُنتجه الوكيل (أسماء المشاريع، الملفات، الترويسات، حقوق النشر، الواجهات) يحمل اسم
**FoxSD** وبيانات التواصل **foxsd520@gmail.com** فقط. الوكيل ممنوع من ذكر أي شركة أو علامة
تجارية خارجية في أي مخرَج.

## التشغيل

```bash
pip install -r requirements.txt
```

### طلب واحد

```bash
python nour_ai.py "ابنِ لي موقعًا تعريفيًا من صفحة واحدة"
```

### الوضع التفاعلي

```bash
python nour_ai.py
```

أوامر الوضع التفاعلي:

- `/exit` — الخروج
- `/new` — بدء محادثة جديدة

### تحديد مجلد البناء

```bash
python nour_ai.py --workspace ./projects "ابنِ نظام إدارة مهام"
```

## الإعداد

| المتغير | الوصف |
|---|---|
| `LLM_API_KEY` | صلاحية المحرّك الداخلي (تُجلب تلقائيًا داخل بيئة FoxSD إن لم تُضبط) |
| `LLM_BASE_URL` | عنوان المحرّك الداخلي |
| `LLM_MODEL` | النموذج المستخدم (افتراضيًا نموذج FoxSD الداخلي) |
